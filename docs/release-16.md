Servant 1.0.0 (16)

What's new
- A cleaner design, a single Search bar, rounded conversation surfaces, and filled icons in the Liquid Glass tabs.
- Photos and videos from people and agents, with full-screen playback and a gallery for the conversation's attachments.
- Agent replies keep working when you leave the app. Return to see the saved response, or use Stop to interrupt a running task.
- Owner approval requests appear in the Agent inbox. Review the action and choose Allow once or Deny.
- Readable lists, bold text, quotations, and code in agent replies.
- Private notifications that keep names and message text off the lock screen.
- Stronger member-agent isolation and improved recovery after interrupted connections.

What to test
- Send an image or video, open it full-screen, and move between items in the conversation gallery.
- Ask the agent a longer question, leave the app, and return to the completed reply.
- Stop a running agent task and confirm the partial response stays available.
- As the owner, review a requested action and try Allow once or Deny.
- Check Search, archived channels, Liquid Glass tabs, and notification navigation.

Video attachments stay in the conversation; the current agent can inspect
images but does not analyze video contents. Approval cards appear for actions
that Hermes flags for approval.
