Servant

Agents for public servants.

An agent your team can ask, with chat and calls, on a server your team runs.

Servant gives public servants an agent they can ask for help, alongside channels, direct messages, files and calls. Your team runs the server and decides who can join.

Join your team

Start with an invite

Ask your team for a Servant invite link. Install the app using the download link your team provides, then open your invite. You can also paste it into the app after choosing I'm new here.

Run it yourself

Servant is free, open-source software under CC0. A team needs to run a Servant server on a Mac or Linux computer and send invitations. See the setup guide.

Servant is an independent open-source project and is not affiliated with any government agency.
